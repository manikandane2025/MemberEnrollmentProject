# Sprint-04 Demo Checklist

## Pre-Demo Setup
- Checkout `sprint/S04` branch.
- Start backend on port 8001.
- Start frontend on port 3002.
- Open `http://localhost:3002`.

## Demo Flow (5-7 min)
1) Show plan catalog with tiers.
2) Filter by tier (Silver/Gold/etc.).
3) Compare two plans.
4) Select a plan for a member.
5) Refresh and show selection persisted.

## Talking Points
- Plans are seeded for demo consistency.
- Tier filters support quick plan narrowing.
- Plan selection is stored per member for downstream enrollment.
