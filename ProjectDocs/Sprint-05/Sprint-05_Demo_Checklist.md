# Sprint-05 Demo Checklist

## Pre-Demo Setup
- Checkout `sprint/S05` branch.
- Start backend on port 8001.
- Start frontend on port 3002.
- Open `http://localhost:3002`.

## Demo Flow (5-7 min)
1) Select a member profile.
2) Upload a PDF or image.
3) Show metadata in the document list.
4) Upload a TXT to show validation error.

## Talking Points
- File validation enforces type and size limits.
- Uploads are stored and linked to members.
- Metadata supports audit and compliance needs.
