# Sprint-06 Demo Checklist

## Pre-Demo Setup
- Checkout `sprint/S06` branch.
- Start backend on port 8001.
- Start frontend on port 3002.
- Open `http://localhost:3002`.

## Demo Flow (5-7 min)
1) Toggle email and SMS opt-in.
2) Send Email confirmation.
3) Send SMS notification.
4) Show notification audit entries.

## Talking Points
- Templates allow consistent messaging.
- Opt-in enforcement supports compliance.
- Audit log provides traceability.
